# v0.12.0 — Axiomatic Claim Type Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Introduce a third claim type `axiomatic` alongside `normal` and `citation`; add a parallel `ClaimAxiomLibrary`; generalize the citation library's interface to be reusable across both connection libraries; rename `claimCitations` → `citations` across `PropositCore`, snapshot, on-disk, and CLI for symmetry with the new `axioms`; replace `populateFromCitations` with a unified `populateFromSupports`; teach `ArgumentEngine.evaluate` and `checkValidity` to treat axiomatic-bound variables as forced `true`; ship a v0.12 CLI migration.

**Architecture:** Core claim type union expands to `'normal' | 'citation' | 'axiomatic'`. A generic `TClaimConnectionLibraryManagement<TConn>` interface is implemented by both `ClaimCitationLibrary` and the new `ClaimAxiomLibrary`. Both libraries share the connection schema shape (`claimId`/`supportingClaimId` field pair) and live as parallel public fields on `PropositCore` (`citations`, `axioms`). `ManagedDerivationPremiseEngine.populateFromSupports` builds the derivation antecedent from both libraries in one shot. Evaluation gains a pre-pass in `ArgumentEngine.evaluate` / `checkValidity` that forces axiomatic-bound variables to `true`; the standalone evaluator stays claim-type-agnostic. A `.proposit-v0.12` CLI marker gates a multi-file backfill (rename `claim-citations.json` → `citations.json`, rewrite wrapper + field names + checksums, create `axioms.json`).

**Tech Stack:** TypeScript, TypeBox schemas, Vitest, pnpm, ESM. Same toolchain as v0.10/v0.11.

**Spec:** [`docs/superpowers/specs/2026-05-11-axiomatic-claim-type-design.md`](../specs/2026-05-11-axiomatic-claim-type-design.md)

**Dependency:** v0.11.x (currently `0.11.2`) is on `main`. This plan targets v0.12.0 — a breaking version.

- [ ] **Step 2: Replace populateFromCitations with populateFromSupports**

Delete the existing `populateFromCitations` method and add:

```ts
/**
 * One-shot helper that builds the antecedent of this derivation premise
 * from the current global support (citations + axiom invocations) of the
 * derived claim.
 *
 * Behavior by total support count `n = citations + axioms`:
 *   - n = 0: no change. Premise stays in its current form (typically
 *     naked-Q, indicating "no support given").
 *   - n = 1: `IMPLIES(VarExpr(S1), Q)`.
 *   - n ≥ 2: `IMPLIES(formula(OR(VarExpr(S1), …, VarExpr(Sn))), Q)`.
 *     Citations come first, axioms second; source order preserved within
 *     each. The formula buffer between IMPLIES and OR is auto-inserted by
 *     the engine's standard grammar.
 *
 * Materializes a claim-bound variable for each supporting claim via
 * `argumentEngine.ensureClaimBoundVariable(supportingClaimId)`.
 *
 * @throws InvariantViolationError(DERIVATION_ANTECEDENT_NON_EMPTY) when
 *         the antecedent slot is already filled.
 *
 * @since 0.12.0
 */
public populateFromSupports(
    citationLib: ClaimCitationLibrary,
    axiomLib: ClaimAxiomLibrary,
    argumentEngine: TVariableMaterializer
): void {
    const premise = this.premise as TCoreDerivationPremise
    const derivedClaimId = premise.derivedClaimId

    // 1. Reject if antecedent is already non-empty.
    const rootId = this.rootExpressionId
    if (rootId !== undefined) {
        const root = this.expressions.getExpression(rootId)
        if (
            root &&
            root.type === "operator" &&
            (root.operator === "implies" || root.operator === "iff")
        ) {
            const children = this.expressions
                .getChildExpressions(rootId)
                .sort((a, b) => a.position - b.position)
            const antecedent = children[0]
            if (antecedent) {
                throw new InvariantViolationError([
                    {
                        code: DERIVATION_ANTECEDENT_NON_EMPTY,
                        message: `${DERIVATION_ANTECEDENT_NON_EMPTY}: derivation premise already has a non-empty antecedent`,
                        entityType: "premise",
                        entityId: premise.id,
                        premiseId: premise.id,
                    },
                ])
            }
        }
    }

    // 2. Collect supporting connections from both libraries.
    const citationConnections =
        citationLib.getConnectionsForClaim(derivedClaimId)
    const axiomConnections = axiomLib.getConnectionsForClaim(derivedClaimId)
    const totalCount = citationConnections.length + axiomConnections.length
    if (totalCount === 0) return

    // 3. Materialize claim-bound variables for each support (citations first,
    //    axioms second, source order within each).
    const supportingVariables: TClaimBoundVariable[] = []
    for (const conn of citationConnections) {
        supportingVariables.push(
            argumentEngine.ensureClaimBoundVariable(conn.supportingClaimId)
        )
    }
    for (const conn of axiomConnections) {
        supportingVariables.push(
            argumentEngine.ensureClaimBoundVariable(conn.supportingClaimId)
        )
    }
    for (const sv of supportingVariables) {
        if (!this.variables.hasVariable(sv.id)) {
            this.variables.addVariable(sv as unknown as TVar)
        }
    }

    // 4. Build the antecedent tree.
    this.buildAntecedentFromSupportingVariables(supportingVariables)

    // 5. Validate the final tree is well-formed.
    this.assertWellFormed()
}
```

### Task 34: v0.12 migration script

**Files:**

- Create: `src/cli/storage/migrate-v0.12.ts`
- Modify: `src/cli/engine.ts`

- [ ] **Step 1: Write the migration script**

Create `src/cli/storage/migrate-v0.12.ts` modeled on `migrate-v0.11.ts`:

```ts
import fs from "node:fs/promises"
import path from "node:path"
import { getStateDir } from "../config.js"
import { entityChecksum } from "../../lib/core/checksum.js"
import { DEFAULT_CHECKSUM_CONFIG } from "../../lib/consts.js"

const MARKER = ".proposit-v0.12"

/**
 * One-time migration of CLI state directories from pre-v0.12 to v0.12:
 *
 *   - Rename `claim-citations.json` → `citations.json`.
 *   - Rewrite the wrapper field `claimCitations` → `connections`.
 *   - Rename per-citation field names: citingClaimId → claimId,
 *     citingClaimVersion → claimVersion, sourceClaimId → supportingClaimId,
 *     sourceClaimVersion → supportingClaimVersion.
 *   - Recompute each citation's checksum with the new field set.
 *   - Create `axioms.json` if absent, initialized to `{ connections: [] }`.
 *
 * Each step is idempotent: a partial-failure rerun lands on the same end
 * state. The `.proposit-v0.12` marker is the last write; if any prior step
 * failed, the next CLI invocation re-runs all prior steps.
 */
export async function migrateV012(): Promise<void> {
    const stateDir = getStateDir()
    const markerPath = path.join(stateDir, MARKER)
    try {
        await fs.access(markerPath)
        return // Already migrated.
    } catch {
        // Marker missing — proceed.
    }
    try {
        await fs.mkdir(stateDir, { recursive: true })
    } catch {
        // Surfaced by later steps if it actually matters.
    }

    const oldCitationsPath = path.join(stateDir, "claim-citations.json")
    const newCitationsPath = path.join(stateDir, "citations.json")
    const axiomsPath = path.join(stateDir, "axioms.json")

    // Step 1: Read raw content. If already-migrated `citations.json` exists,
    // skip the rewrite. Otherwise read `claim-citations.json`; if neither
    // exists, treat as fresh and write a new-format empty citations file.
    let rawContent: string | null = null
    let sourceIsLegacy = false
    try {
        rawContent = await fs.readFile(newCitationsPath, "utf-8")
    } catch {
        try {
            rawContent = await fs.readFile(oldCitationsPath, "utf-8")
            sourceIsLegacy = true
        } catch {
            // Neither exists — treat as fresh.
            await fs.writeFile(
                newCitationsPath,
                JSON.stringify({ connections: [] }, null, 2)
            )
        }
    }

    if (rawContent !== null) {
        const parsed = JSON.parse(rawContent) as Record<string, unknown>
        const needsShapeRewrite =
            "claimCitations" in parsed && !("connections" in parsed)
        const list = (
            (parsed.connections ?? parsed.claimCitations ?? []) as Array<
                Record<string, unknown>
            >
        ).map((c) => {
            const renamed: Record<string, unknown> = { ...c }
            if ("citingClaimId" in renamed) {
                renamed.claimId = renamed.citingClaimId
                delete renamed.citingClaimId
            }
            if ("citingClaimVersion" in renamed) {
                renamed.claimVersion = renamed.citingClaimVersion
                delete renamed.citingClaimVersion
            }
            if ("sourceClaimId" in renamed) {
                renamed.supportingClaimId = renamed.sourceClaimId
                delete renamed.sourceClaimId
            }
            if ("sourceClaimVersion" in renamed) {
                renamed.supportingClaimVersion = renamed.sourceClaimVersion
                delete renamed.sourceClaimVersion
            }
            // Recompute checksum using v0.12 field set.
            const fields = DEFAULT_CHECKSUM_CONFIG.claimCitationFields!
            renamed.checksum = entityChecksum(renamed, fields)
            return renamed
        })
        const newContent = { connections: list }
        if (sourceIsLegacy || needsShapeRewrite) {
            await fs.writeFile(
                newCitationsPath,
                JSON.stringify(newContent, null, 2)
            )
            if (sourceIsLegacy) {
                await fs.rm(oldCitationsPath, { force: true })
            }
        }
    }

    // Step 2: Init axioms.json if absent.
    try {
        await fs.access(axiomsPath)
    } catch {
        await fs.writeFile(
            axiomsPath,
            JSON.stringify({ connections: [] }, null, 2)
        )
    }

    // Step 3: Marker.
    await fs.writeFile(markerPath, new Date().toISOString())
    process.stderr.write(
        `[proposit] Migrated state directory to v0.12.0 format at ${stateDir}\n`
    )
}
```
