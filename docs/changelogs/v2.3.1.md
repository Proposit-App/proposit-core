# upcoming changelog

## Added

- `ArgumentEngine.patchExpressionAppFields(expressionId, fields): void` — a
  public API for consumers to patch application-specific fields onto an
  expression across all premises and atomically mark it dirty. The `fields`
  parameter is typed as `Partial<TExpr>`, generic over the engine's expression
  type, so consumer-supplied app fields (e.g. `creatorId`, `createdOn`) are
  accepted without `as unknown` casts. Throws if the expression ID is unknown.

## Tests

- `patchExpressionAppFields` — four new tests in `test/core.test.ts`: verifies
  that a checksum-bearing field patch changes the expression checksum, that
  dirty propagation causes the parent's `combinedChecksum` to recompute, that
  unknown IDs throw, and that `snapshot()` reflects both patched values and
  post-patch checksums.
