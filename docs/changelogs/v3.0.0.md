# v3.0.0 changelog

## Breaking

- **Root barrel (`src/lib/index.ts`) no longer re-exports opinionated
  extensions** (commit 0eb5787). Removed from the package-root
  (`@proposit/proposit-core`) entry:
    - `createOpenAiResponsesProvider`, `TCreateOpenAiResponsesProviderOptions`,
      `TOpenAiFetch`, and the OpenAI error classes (`NonRetryableLlmError`,
      `QuotaExhaustedLlmError`, `RateLimitLlmError`, `SchemaValidationLlmError`,
      `ToolLoopExhaustedError`, `TransientLlmError`) — still exported from
      `@proposit/proposit-core/extensions/openai`.
    - `createReviewTurn`, `createSimulateTurn`, `createDistillTurn`,
      `TDistillTurnOptions`, `TDistillOutput` — still exported from
      `@proposit/proposit-core/builder`.

    Migration: change the import source only; the symbols and their behavior are
    unchanged. The root barrel now carries the engine + pipeline framework only,
    matching the pre-existing subpath-only treatment of the ingestion pipelines.

## Added

- **New subpath `@proposit/proposit-core/pipelines/scheduling`** (commit
  0eb5787): pure, descriptor-based DAG-eligibility helpers for driving a
  pipeline out of process — `isStageEligible`, `hasRequiredFailureUpstream`,
  `computeDagProgress`, the `TStageDescriptor` / `TDagProgress` types, and
  re-exports of `depId` / `isOptionalDep` / `optional` / `TDepSpec` /
  `TOptionalDep`. Semantics mirror the in-process scheduler exactly (required
  dep satisfied only when `completed`; optional dep satisfied on any terminal
  outcome; required non-`completed` terminal dep makes the dependent
  skip-eligible).
- **Canonical ingestion stage-id constants** on
  `@proposit/proposit-core/pipelines/ingestion` (commit 0eb5787):
  `INGESTION_SCHOLAR_STAGE_IDS`, `INGESTION_SCRIBE_STAGE_IDS`, and
  `getCanonicalStageIds(pipelineId)`. A test asserts each list equals
  `pipeline.stages.map((s) => s.id)` to guard against drift from the factories.

## Changed

- Retired the redundant "Argument Ingestion" taxonomy Feature
  (`docs/taxonomy/argument-ingestion`); the ingestion pipeline code is
  unchanged. The "Argument Builder" Feature is retained.
- Adapted the repo's own tests to import the OpenAI provider and builder turns
  from their subpaths rather than the root barrel.

## Docs

- Retire the dead `docs/inbox/` change-request pattern in favour of `tcw work`.
  Rewrote the AGENTS.md incoming-work paragraph to the `tcw work inbox
list`→`show`→`accept` flow, dropped the dead `.prettierignore` entry, and
  removed a `docs/inbox/...` pointer from a `core.test.ts` comment.
