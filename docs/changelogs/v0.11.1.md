# Changelog — v0.11.1

Commit range: `v0.11.0` → `v0.11.1`

## Engine

- `796b5c4` fix(argument-engine): preserve premise sibling extras through fromData — restores all non-typed-bag sibling properties (e.g. `title`, `role`, `createdOn`, `creatorId`) on premise rows passed to `ArgumentEngine.fromData()`. The previous typed-bag heuristic in `parsePremiseArgsInternal` mistook DB-shape rows for typed-bag inputs whenever `type: string` was present and silently discarded every property other than `type`/`derivedClaimId`/`extras`/`symbol`. The fromData call site now explicitly extracts `type`/`derivedClaimId` and forwards the remaining siblings under the typed-bag's `extras` slot. No checksum impact (these fields are excluded from `premiseFields`). Resolves the workaround that `proposit-server`'s `constructEngineFromData` was applying via post-restore `pe.updateExtras()` calls.
