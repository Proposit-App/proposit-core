# upcoming changelog

## Changed

- `src/lib/pipelines/llm-stage-helpers.ts` — extracted the `llmStage` retry
  loop's single-attempt body into `runLlmStageAttempt` (request build/emit,
  provider call, outcome classification, backoff). Behavior unchanged.
- `src/lib/pipelines/scheduler.ts` — `executePipeline` restructured (finalize
  wiring + event `emit` plumbing hoisted) with no behavior change.
- `src/lib/llm/types.ts` — `TLlmTokenUsage` is now derived from a new
  `LlmTokenUsageSchema` (TypeBox) rather than a hand-written type.
- `src/lib/pipelines/types.ts` — `TProcessingFailure` is now derived from a new
  `ProcessingFailureSchema` (TypeBox).

## Added

- Exported `LlmTokenUsageSchema` and `ProcessingFailureSchema` (TypeBox) from
  the public barrel, so consumers can validate these shapes at runtime.
- Exported the stage input types `TAssignVariablesInput`,
  `TCompileFormulasInput`, `TFreeformRelation`, `TValidateFormulasInput`, and
  `TDistillOutput`.

Refactor plus additive schema/type exports — no behavior, CLI, or wire-format
change.
