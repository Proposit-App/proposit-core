# v3.1.0 changelog

## Added

- **`ArgumentEngine.deriveDefaultAssignment(): TCoreVariableAssignment`** — derives
  a variable-keyed default assignment (`true` / `null`, never `false`) purely from
  claim type and immediate support structure. `D(claim)`: citation/axiomatic →
  `true`; normal → `true` iff its derivation premise's immediate antecedent
  Kleene-evaluates `true` when each immediately-referenced claim is seeded `true`
  iff citation/axiomatic (one level, no recursion), else `null`. Added to the
  `TArgumentEvaluation` interface.
- **`ArgumentEngine.evaluateWithDefaults(overrides?, options?)`** — merges caller
  overrides over the derived defaults and calls `evaluate`, dropping
  default-sourced axiomatic-bound keys so the defaults reconcile with the
  existing axiomatic force-true pre-pass without tripping
  `AXIOM_VARIABLE_ASSIGNMENT_FORBIDDEN`.
- **`ArgumentEngine.getVariableIdForClaim(claimId)` / `getClaimIdForVariable(variableId)`**
  — pure (non-creating) accessors exposing the `claimId ↔ variableId` seam that
  consumers keying by `claimId` depend on.
- **`evaluateSubtreeKleene(...)`** exported from
  `src/lib/core/evaluation/argument-evaluation.ts` — a total, non-throwing Kleene
  evaluator over an expression subtree, used to score derivation antecedents at
  default-derivation time.

## Notes

- No wire-format, grammar-rule-code, or engine-error-code changes; the additions
  are purely additive public API. `deriveDefaultAssignment` reports axiomatic-bound
  variables as `true` in agreement with the evaluate-time pre-pass, but callers
  feeding the raw map to `evaluate` must strip axiomatic-bound keys (or use
  `evaluateWithDefaults`).
- Axiom vs. citation asymmetry, confirmed against the engine: only **axiomatic**
  claims are engine-forced-true (and reject explicit assignment). **Citation**
  claims are free — `evaluate` accepts an explicit citation assignment and does
  not force one, so the map's citation `true` is load-bearing and is **kept**
  (not dropped) during evaluation. A consumer building its own effective
  assignment must strip axiomatic keys but keep citation keys; citation defaults
  are reviewer-overridable, axioms are not.
