# upcoming changelog

## Changed

- `src/lib/parsing/schemata.ts` — deep-clone now uses `structuredClone` instead of
  `JSON.parse(JSON.stringify(...))`.
- `src/lib/grammar/validators/structural.ts` — simplified a redundant
  `!== null && !== undefined && !== ""` triple-check to `!= null && !== ""`.
- `src/lib/utils/collections.ts` — `sortedCopyById` drops a redundant intermediate
  `.map()` spread.
- `src/lib/consts.ts` — the repeated 8-element checksum-config key array (used by
  `normalizeChecksumConfig`, `serializeChecksumConfig`, `createChecksumConfig`) is
  now a single module-level const. Internal-only — no change to `createChecksumConfig`'s
  public signature or behavior.
- `src/lib/core/argument-engine.ts` / `src/lib/core/premise-engine.ts` — the
  near-identical `cachedMetaChecksum` / `cachedDescendantChecksum` /
  `cachedCombinedChecksum` caching logic in both classes is now a shared
  `HierarchicalChecksumCache` base class (`src/lib/core/checksum-cache.ts`).
  Internal-only — no public API or behavior change.
- `src/cli/schemata.ts` — removed unused `CliArgumentSchema`/`TCliArgument` and
  `CliClaimSchema`/`TCliClaim` (zero callers, not part of the public barrel).

Internal cleanup only — no public API, CLI surface, or behavior change.
