# upcoming changelog

## Added

- `BasicsCitationClaimExtension` (`@proposit/proposit-core/basics`) gains an optional `citationTypeGuess` field — a best-guess IEEE reference type (one of the 33 `IEEE_REFERENCE_TYPES`) or `"unknown"`. Optional, so it is non-breaking to consumers validating older canonical-claim data. Both ingestion pipelines (scholar `claim-canonicalization`, scribe `extract`) now produce it for citation claims; their prompts ask the model to fill it.

## Changed

- **Ingestion finalize now emits an explicit unparsed citation for every citation claim.** A claim classified `citation` stays typed `citation` and carries a `citation: { type: "unparsed", text, citationTypeGuess, url? }` object. `text` is the claim title (falling back to the classifier's recorded source string, then the claim id), so a url-less reference renders its text instead of a blank proposition. The guess is sanitized against the 33 IEEE literals + `"unknown"` and clamped to `"unknown"` for any absent or out-of-enum value — the model is never trusted to stay in-enum.
- **Removed the url-presence band-aid in finalize.** A url-less citation used as a logical node was previously demoted to `normal`; it now stays `citation` with its unparsed citation. Premise placement is handled separately (see below), so a citation no longer lands in a freeform premise.
- **The ingestion relation model collapsed to a single directional `inference` relation.** The relation-extraction stage's output schema drops the `support` / `joint-support` / `derivation-support` relation kinds and the `sources` / `target` shape in favour of one relation: `{ relationId, type: "inference", antecedents: string[], consequent, evidence }`, compiling to `IMPLIES(AND(antecedents), consequent)` — a single antecedent reproduces the old `support`. The exported relation type is renamed `TRelation` → `TInferenceRelation`, `FormulaCompilationOutputSchema` now carries `derivationBacking` (`[{ derivedClaimMiniId, supportingClaimMiniIds }]`), and `FormulaPremiseRoleHintSchema` narrows to `Union("freeform", "conclusion")`. These are internal ingestion-pipeline types, not part of the engine/parser public surface.
- **Citation/axiomatic claims are sorted out of freeform premises deterministically.** Formula compilation runs `sortInferenceRelations` over the inference relations using the resolved claim types: an `inference` antecedent that resolves to a `citation`/`axiomatic` claim is routed into `derivationBacking` (carried through finalize to the parser, which builds a derivation-premise edge); antecedents that resolve to `normal` stay as freeform implication premises. A relation with an unresolved or typed consequent, an unresolved antecedent, or no antecedents after de-duplication is dropped and recorded as a `warning` processing failure (`droppedTypedConsequent` / `droppedUnresolvedClaim` / `droppedEmptyAntecedents`) — one bad relation degrades to an omitted premise, never a failed import. An antecedent whose type cannot be resolved is **never** defaulted to `normal` — that default was the path that let a citation reach a freeform premise.
- The parsed-argument schema gains an optional `derivationBacking` (`ParsedDerivationBackingSchema`); the parser builds citation/axiomatic derivation-premise edges from it instead of scanning compiled `IMPLIES` formulae.

## Tests

- `test/extensions/pipelines/stages/inference-sort.test.ts` — a matrix over `sortInferenceRelations`: citation/axiomatic antecedents route to derivation backing, normal antecedents stay freeform, self-references and duplicate antecedents are dropped, an empty/typed/unresolved consequent or antecedent drops the relation with the right warning code, and an unresolved antecedent is never treated as `normal`.
- `test/extensions/pipelines/stages/schemas.test.ts` — the reshaped relation/compilation schemas accept the inference shape and reject the removed relation kinds.
- `test/extensions/pipelines/finalize-response-v2.test.ts` — the citation-claim suite asserts a citation source stays `citation` with a well-formed unparsed citation, that an absent or out-of-enum guess clamps to `"unknown"`, that a valid guess and a present url ride through, and that no loose `citationTypeGuess` field is left on the claim.
- `test/parser.test.ts` — the derivation-premise suite builds edges from `derivationBacking` instead of scanning `IMPLIES` formulae.
- Re-recorded the v2 + scribe golden fixtures across all five scenarios for the inference relation model.
