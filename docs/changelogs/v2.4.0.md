# v2.4.0 changelog

## Added

- `TResponseId` brand type on `TLlmRequest.previousResponseId` (additive).
- `src/lib/conversation/` — conversation primitive:
  `executeTurn`, `createConversation`, `ConversationClosedError`,
  `TTurnInput`, `TTurnResult`, `TExecuteTurnDeps`, `TConversation`,
  `MultiTurnInput`, `MultiTurnOutput`.
- `src/extensions/builder/` — Argument Builder turn factories:
  `createReviewTurn`, `createSimulateTurn`, `createFinalizeTurn`.
- `src/cli/builder-repl.ts` — terminal Argument Builder REPL entry point.
- OpenAI provider: threads `TLlmRequest.previousResponseId` as
  `previous_response_id` on the Responses API request body.

## Changed

- **New subpath exports**: `@proposit/proposit-core/conversation` and
  `@proposit/proposit-core/builder`.

## Tests

- `test/conversation.test.ts` — 15 new tests covering:
  `executeTurn` (output, failure, onComplete, token usage),
  `createConversation` (initial state, response-ID threading, token
  accumulation, branchFrom, throw-after-close, close flag),
  builder turns (stage id, dependsOn, outputSchema),
  contract types (composition),
  previousResponseId through provider wrapper.
