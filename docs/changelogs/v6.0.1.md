# v6.0.1 changelog

## Fixed

- `checkLink` answered `attemptedSupport: false` for the links of a reply (a
  response whose target is a response), and for a link on a negated
  expression of a standard argument, even when another premise gave a reason
  for the link. The consequent of each reason had its `NOT`s set aside but the
  link's referent did not, so a referent that was itself a negation never
  matched. Both are now compared up to negation. Pinned by
  `test/core/response-check.test.ts`.
