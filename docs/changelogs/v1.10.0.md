# v1.10.0 changelog

Commit range: `v1.9.0..v1.10.0`.

## New

- **`backgroundStreamMode` option on `createOpenAiResponsesProvider`** — third execution branch in `fetchResponseEnvelope` (`provider.ts`): POSTs with `{ background: true, stream: true, store: true }` and consumes the SSE stream live. Response keeps generating server-side after a connection drop. `backgroundStreamMode: true` takes priority over `backgroundMode` when both are set.
- **`retrieveResponse(id, options): Promise<TRetrievedResponse>`** — new exported function from `src/extensions/openai/index.ts`. Retrieves a stored OpenAI response by id (GET `/v1/responses/{id}`). Returns `{ status, output?, tokenUsage?, rawResponseId }`. HTTP 404 throws the new `ResponseNotFoundError` (retention window elapsed).
- **`ResponseNotFoundError`** — new typed error class in `src/extensions/openai/errors.ts`, thrown by `retrieveResponse` on 404. Carries `responseId` for the caller.
- **`TRetrievedResponse` / `TResponseStatus` types** — exported from `src/extensions/openai/index.ts`.
- **`stage:llm-response-created` pipeline event** — new `TPipelineEvent` variant (`src/lib/pipelines/types.ts`). `llmStage` emits `{ stageId, attempt, responseId }` immediately after `respond()` returns a `rawResponseId`, before `stage:llm-call`. `prefixSubPipelineEvent` in `stage-helpers.ts` handles the new variant.
- **`rawResponseId` on `stage:llm-call`** — optional `rawResponseId?: string` field added to the `stage:llm-call` event payload.

## Changed

- **`getResponseById`** now throws `ResponseNotFoundError` on HTTP 404 rather than routing through `classifyHttpError`. The background poll loop in `runBackground` remains unaffected (404 mid-poll is now a typed `ResponseNotFoundError` rather than a generic `NonRetryableLlmError`).
- `createOpenAiResponsesProvider`: `useBackground` is forced `false` when `useBackgroundStream` is `true`, so the two options are composable without mutual exclusion requirements on the caller.
- No-tools guard now covers `useBackgroundStream || useBackground` in a single check.
