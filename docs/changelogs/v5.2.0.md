# v5.2.0 changelog

## Changed

- Every scholar and scribe ingestion stage now defaults to `gpt-6-sol`
  (`*_MODEL` constants; `builder-repl`'s default too). Each stage keeps its
  reasoning effort; scribe's `extract` and `structure` still send none.
- `TLlmModel` adds `gpt-6-sol` and `gpt-6-luna`. `TReasoningEffort` adds
  `none`, `xhigh` and `max`; the stage effort constants are typed
  `TReasoningEffort`. GPT-6 rejects `minimal`, so the OpenAI provider and
  `submitBackgroundResponse` send `low` in its place to any `gpt-6*` model.
- `FINALIZE_V2_FAILURE_TEXTS.noConclusion` is now "Couldn't work out how these
  claims connect to a conclusion."
- The scribe `structure` and `relation-extraction` prompts say relation titles
  must all differ, and ask for the relations (and, for `structure`, the
  conclusion) the author actually argues: an argument with at least two normal
  claims has at least one, but support the author does not give must not be
  invented, and claims that genuinely do not connect get an empty answer.

## Added

- `llmStage` takes an optional `checkOutput(output, ctx)`; a returned
  `TLlmOutputCheckFailure` (`{ code, message }`, exported) is retried like a
  schema mismatch and, once attempts run out, fails the stage with that code
  and message. `completeStage` takes an optional sixth argument,
  `{ upstream, input }`, so the check also runs out of process; without it
  only the schema is checked.
- `checkArgumentStructure` and `NO_ARGUMENT_STRUCTURE_FAILURE` (stages
  barrel). Scribe `structure` refuses an answer with no relation or no
  conclusion candidate, and scholar `relation-extraction` one with no
  relation, when at least two canonical claims are normal. Each canonical
  claim counts once, typed by its classification when it has one, as the
  prompts list them; a repeated or unknown classification id counts for
  nothing. The final failure is
  `NO_ARGUMENT_STRUCTURE`, severity `error`.
- `finalizeResponseV2` composes the title of a step whose authored title
  repeats an earlier premise's, and records `PREMISE_TITLE_DUPLICATE` (warning)
  when even the composed title repeats one.

- `locateSourceAnchor` gains a last, approximate step (word-level, with quote
  marks, dashes, ellipses, case and edge punctuation folded): `reworded` —
  fewest changed words, quote ≥ 5 words, ≤ 1 in 8 and ≤ 3 changed, and no
  separate passage as good; `joined` — only when nothing qualifies, the
  longest word-for-word run if ≥ 8 words, ≥ half the quote, and found in
  exactly one place (a repeated run, or two runs of that length, give no
  anchor). Words are compared after NFC normalization and split at em and en
  dashes as well as whitespace; a standalone dash is not a word. The
  match carries `approximate: TApproximateAnchorRule` (new exported type);
  the anchor is the input's own text. Finalize reports each as
  `SOURCE_ANCHOR_APPROXIMATE` (`context.rule`, `context.anchoredQuote`), and
  an approximate quote several passages match equally as
  `SOURCE_ANCHOR_AMBIGUOUS` with no anchor and no `context.startUtf16`.

## Fixed

- `finalizeResponseV2` no longer uses an authored conclusion title that
  equals any relation's authored title (case and surrounding space ignored);
  the conclusion premise's title is composed from its claim instead. The
  scribe structure prompt also requires the two to differ.
- `finalizeResponseV2` no longer uses an authored step or conclusion title
  that names a claim by its internal id (a standalone word like `c1`, as in
  "Inference from c1"); that premise's title is composed instead.
- Scribe (`argument-ingestion-scribe`, now version 1.1.0): every source
  (citation) claim now backs the normal claim it supports, even when
  `scribe-structure` leaves it out of its relations. `extract`'s output gains a
  required `sourceSupport` array (`{ sourceMiniId, supportedMiniId }`), and its
  prompt requires one citation claim per explicit link offered as evidence. The
  `relation-extraction` adapter appends one single-antecedent relation
  (`source-<source>-<supported>`) per named pair, and for a source neither named
  nor used by `structure` (read off what `sortInferenceRelations` makes of
  structure's relations, so a relation the compiler drops attaches nothing), one
  to the normal claim whose mention overlaps the source's most, else the nearest
  normal claim in the same sentence on either side, else the nearest normal
  claim whose mention ends before it. New warnings:
  `SOURCE_ATTACHMENT_INVALID_SOURCE` (a pairing whose source is unknown or not a
  citation), `SOURCE_ATTACHMENT_INVALID_TARGET` (a named target that is unknown
  or not normal) and `SOURCE_ATTACHMENT_UNATTACHED`.
- Scribe claim `role` values change: `finalizeResponseV2` derives roles from the
  published relations, which now include the source relations, so a source claim
  and a normal claim that only a source relation touches go from `intermediate`
  to `premise`.
- Scribe's `conclusion-selection` adapter runs its graph fallback over
  `structure`'s own relations, no longer the `relation-extraction` slot.

  observed `stage:retry`.
- New tests for distinct premise titles, the `minimal` → `low` mapping on both

- Re-recorded the scribe golden corpus.
- Re-recorded the relation, conclusion and scribe structure answers of both
  golden corpora for the reworded prompts, dropping the replaced records. The
  `ambiguous-conclusion` fixture's text now states its conclusion, and both of
  its recordings were captured again in full.
- New `source-anchors-approximate` tests, including a spliced and a reworded
  quote from a real import.
