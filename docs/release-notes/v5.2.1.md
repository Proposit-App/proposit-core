# v5.2.1 release notes

## Fixed

### Imported claim titles are no longer cut off mid-word

With `gpt-6-sol`, the default model since 5.2.0, claim titles from an import
could stop partway through a word, with nothing to show they were shortened —
"Comparison covers major politicians since 177" for a claim about 1776. The
length limit was being sent to the model as a hard stop, which the newer model
obeys by simply ceasing to write. The limit is now given to the model as an
instruction instead, and a title that still runs long is shortened to the last
whole word that fits, followed by "…". The same applies to every other text
the import shortens, such as step and argument titles.
