# upcoming release notes

## Public API: `ArgumentEngine.patchExpressionAppFields`

A new public method `patchExpressionAppFields(expressionId, fields)` lets
consumers attach application-specific metadata (e.g. `creatorId`, `createdOn`)
to engine expressions without reaching into engine internals. It resolves the
owning premise, applies the patch in place, and marks the expression dirty so
the next checksum flush recomputes from the patched values — atomic
patch-and-mark. Consumers no longer need to mutate internal Map entries or
double-cast through `unknown` to invoke `markExpressionDirty`.
