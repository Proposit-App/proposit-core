# Release notes — v0.11.1

## Bug fixes

- **`ArgumentEngine.fromData()` now preserves all premise row properties.** Previously, when reloading an engine from a database, any extra fields on premise rows beyond the core schema (such as `title`, `role`, `createdOn`, `creatorId`) were silently dropped. Consumers that read those fields off restored premises now see them as expected — no post-load `updateExtras` workaround required.
