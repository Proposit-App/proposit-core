# v3.0.0 release notes

## Changed

- **The package-root import surface is now the pure logic engine.** Two
  opinionated add-ons that used to be importable straight from
  `@proposit/proposit-core` now live only at their dedicated entry points:
    - the ready-made OpenAI provider (and its error types) →
      `@proposit/proposit-core/extensions/openai`
    - the Argument Builder review/simulate/distill turns →
      `@proposit/proposit-core/builder`

    Nothing was removed — if you use these, just import them from the paths
    above. This keeps the main entry point focused on the engine so apps that
    never touch an LLM don't pull provider machinery into their build.

## Added

- **Reusable pipeline stage scheduling.** New helpers at
  `@proposit/proposit-core/pipelines/scheduling` let an application drive a
  pipeline's stage graph itself (deciding what can run next and what to skip)
  with exactly the engine's own rules, instead of re-deriving them by hand.
- **Canonical stage lists for the ingestion pipelines.** The scholar and scribe
  pipelines now publish their ordered stage names (and a lookup by pipeline
  name) from `@proposit/proposit-core/pipelines/ingestion`, so a UI can show
  every stage in order without hardcoding its own copy.
