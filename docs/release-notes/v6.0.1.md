# v6.0.1 release notes

A patch release.

## Fixed

- **A reason for a reply's link is now seen.** `checkLink` on a reply, a
  response that answers another response, reported every link as having no
  reason given (`attemptedSupport: false`), even when the reply offered one.
  It now reports `true` when another premise has the link's content, up to
  negation, on its consequent side, as it already did for a response to a
  standard argument. The same fix applies to a link on an expression of a
  standard argument that is itself a negation.
