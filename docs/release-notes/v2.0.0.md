# v2.0.0 release notes

> **BREAKING:** the IEEE module moved from `extensions/ieee` to `extensions/citations/ieee` (the old subpath is gone, no alias), and the `UnparsedURL` reference type was removed. A new `extensions/citations/unparsed` subpath adds the standalone `UnparsedCitationSchema` family for extracted, not-yet-structured references.

## Citations

- **Citations can now be stored as either a structured reference or an extracted "unparsed" reference awaiting formatting.** A structured citation is a fully-detailed IEEE reference. An unparsed citation is a reference pulled straight from the source text — it keeps the raw text and a best guess at what kind of reference it is — that hasn't been turned into a full IEEE reference yet. This gives a reference a usable identity even before it's fully structured, and leaves room for a later step to convert it. The old catch-all "unparsed URL" reference type is gone; a pasted link is now just a structured `Website` reference, and the IEEE module has moved to a new `extensions/citations/ieee` location alongside the new `extensions/citations/unparsed` family.
