# v3.1.0 release notes

## Added

- **Usage-based default assignments.** New `ArgumentEngine.deriveDefaultAssignment()`
  computes a starting truth value for every variable in an argument from claim
  type and immediate support alone: grounded claims (citations, axioms, and the
  claims they directly support) start **true**, claims still to be proven start
  **unknown**. A default is never **false** — it either affirms a grounded belief
  or withholds. This lets a review surface begin already populated instead of
  blank, and transitively-grounded claims light up as "unknown → true" the moment
  the argument's inferences are evaluated.
- **One-call convenience** `evaluateWithDefaults(overrides?, options?)` merges your
  in-review changes over those defaults and evaluates in a single step, handling
  axiomatic claims correctly so you never hit a "cannot assign an axiom" error.
- **Claim ↔ variable lookups** `getVariableIdForClaim(claimId)` and
  `getClaimIdForVariable(variableId)` let a consumer that thinks in claims
  translate to and from the engine's variable-keyed assignments without creating
  anything.
