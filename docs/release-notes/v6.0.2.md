# v6.0.2 release notes

A patch release.

## Changed

- **The builder's reviewer may format its replies.** The review turn's reply,
  still delivered in `uncategorizedText`, may now use bulleted and numbered
  lists, bold, italic and paragraphs, and puts two or more questions in a
  numbered list. It is asked not to use headings, links, images, tables,
  block quotes or code. A consumer that shows the reply as plain text will
  see the Markdown markers.
- **Distilled arguments stay plain prose.** The distill turn is told to drop
  any Markdown the conversation contains, so `argumentText` keeps the form
  the ingestion pipeline expects.
