# upcoming release notes

## Extracted citations are now recognizable as "needs conversion"

When ingestion pulls a reference out of an argument, it no longer leaves the citation empty. Each citation claim now carries an explicit **unparsed citation** with:

- the display **text** for the reference (so a reference without a link still shows its text instead of appearing blank),
- the link (when one was found), and
- a **best-guess reference type** (e.g. "Website", "JournalArticle") — or "unknown" when the type can't be told.

This is the missing ingredient for surfacing an "extracted — needs IEEE conversion" state with a guessed type that's clearly flagged as a guess. The guess is always validated against the known reference types, so it can never be an unexpected value.

## Citations and axioms stay in valid premises

Ingestion now guarantees that a citation or axiom is only ever placed in a derivation premise, never in a plain "support" premise where it would render as an empty antecedent. Each reference is sorted into a derivation premise automatically; a placement that can't be made valid is dropped on its own — the rest of the argument still imports successfully. This removes a class of imports that previously failed to load.
