# upcoming release notes

Patch release. Internal refactor of the LLM pipeline framework with a small
additive API surface. The `llmStage` retry loop and `executePipeline` were
restructured for readability with no behavior change, and the token-usage and
processing-failure shapes are now exported as TypeBox schemas so consumers can
validate them at runtime. No behavior or wire-format change. See
`docs/changelogs/v2.4.3.md` for the developer-facing detail.
