QA plan

Environment: a builder chat in the consumer, with the 6.0.2 tarball installed and a real model configured. No special accounts.

1. Reviewer formatting. Send an argument to the review turn several times. Expected: replies use only lists, bold, italic and paragraphs. No headings, links, images, tables, block quotes or code appear.
2. Reviewer questions. Expected: when a reply asks two or three questions, they appear as a numbered list. When it asks one, it is a plain sentence.
3. Distilled text. Write some of your own messages with lists and bold, then finish the chat so the argument is distilled. Expected: the distilled argument text is plain prose, with no Markdown symbols such as asterisks or list markers.

Not tested: the simulated user's turns (unchanged), and how the consumer renders Markdown (the consumer's own work). The model's compliance is not guaranteed; a rare stray format is a prompt-quality observation, not a failure of this change.
